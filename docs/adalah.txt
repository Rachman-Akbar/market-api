⚠️ Peringatan keamanan:
Anda baru saja membagikan Personal Access Token di chat ini. Sebaiknya:
1. Revoke token lama di Figma Settings > Security > Personal access tokens
2. Buat token baru untuk penggunaan berikutnya
3. Jangan pernah bagikan token di tempat publik
Token yang sudah bocor bisa disalahgunakan untuk mengakses semua file Figma Anda.
